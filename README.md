## Transfert entre appareils

Dans Aigle > Prévisualisation :

1. Exporter une sauvegarde JSON.
2. Copier le fichier sur l’autre appareil.
3. Ouvrir Vaulty sur l’autre appareil.
4. Importer le fichier JSON.

L’import remplace les données Vaulty locales de l’appareil cible. L’export XLSX reste destiné à la consultation dans Excel.
